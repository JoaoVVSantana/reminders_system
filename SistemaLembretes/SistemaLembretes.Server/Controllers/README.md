## GET /api/lembrete/todos: Retorna todos os lembretes
## GET /api/lembrete/{id}/obterLembrete: Retorna um lembrete pelo ID
## POST /api/lembrete/criarLembrete: Cria um novo lembrete
## PUT /api/lembrete/{id}/atualizarLembrete: Atualiza um lembrete existente
## DELETE /api/lembrete/{id}/apagarLembrete: Remove um lembrete pelo ID
## PATCH /api/lembrete/{id}/concluirLembrete: Marca um lembrete como concluído
