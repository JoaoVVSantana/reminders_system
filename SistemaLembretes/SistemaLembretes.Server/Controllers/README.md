## GET /api/lembrete: Retorna todos os lembretes
## GET /api/lembrete/{id}: Retorna um lembrete pelo ID
## POST /api/lembrete: Cria um novo lembrete
## PUT /api/lembrete/{id}: Atualiza um lembrete existente
## DELETE /api/lembrete/{id}: Remove um lembrete pelo ID
## PATCH /api/lembrete/{id}/concluir: Marca um lembrete como concluído
